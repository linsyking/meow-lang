## 0. The formalism (replaces round 6's block-type language)

Round 6 defined profile grammars as block types + instance families +
junction entries. That language has a defect the charter's item 1c
forces into the open: decb's X-copies have k+1 interior runs, so a
"block type" for them would need k+1 entries — NOT V-fixed size. The
repair is to make the grammar a NESTED-DIRECTIVE system, where the
k-dependence of the profile lives entirely in INDEX RANGES and FORMS,
never in the combinatorial structure.

Fix V once; B = 3; D(k;3). All constants below are V-fixed.

**T_V** := lcm of {2} ∪ {ord_p(3) : p a pattern-length or tiling
modulus occurring in V} ∪ {|p| : pattern lengths}. (V-fixed.)

**D-value forms.** A form of arity d is a function
  τ(k, j_1, ..., j_d) = Σ_{i≤M} q_i·3^{ε_i(k, j̄)} + (a_0 k + Σ_r a_r j_r + c)
where each exponent function ε_i is affine, ε_i = αk + Σ β_r j_r + γ
with (α, β̄, γ) from a V-fixed finite closed family (generated by the
anchored atoms k−c, j_r−c′, c″ and their pairwise/triple sums — round
5's strata); the coefficients q_i, a_r, c are V-fixed rationals with
denominators dividing a V-fixed modulus, REFINED PER CELL: for each
residue class of (k, j̄) mod T_V the periodic refinements (Λ-type
corrections) are fixed constants. Term count M ≤ M_V = 8·#S(V) +
O_V(1) per form (round 5's ledger bound; see the Merge Lemma for the
grammar-level constant).

**Index predicates.** For d ≤ D_V (the S-depth of V), Ind_d(V) is the
smallest family of {0,1}-functions Π(k, j̄) containing:
 (a) affine comparisons [αk + Σ β_r j_r + γ ≥ 0];
 (b) residue tests [j_r ≡ c (mod T_V)];
 (c) EPT-tests [τ_1(k, j̄) = τ_2(k, j̄)] for forms (round 6's EPT:
     per cell of the outer coordinates, eventually periodic in each
     coordinate with V-fixed pre-period);
and closed under Boolean operations and V-fixed affine substitution
j_r ↦ a·j_r + b.

**Directives.** A directive is one of:
 - T(τ): emit one run with value τ(k, ambient index);
 - F(τ, S): emit |S(k)| runs, one per j ∈ S(k), in increasing j;
 - OF(𝔅, S): instantiate the directive LIST 𝔅 once per c ∈ S(k),
   with ambient index c.
Index sets S are given by predicates in Ind_1(V) (in practice:
intervals [lo(k)..hi(k)] with lo, hi V-fixed affine, refined by
residue/EPT masks). Index variables are bound; a form sees its
nearest enclosing family index (and, in the general formalism, all
enclosing indices — arity d = its nesting depth). A PPG is a finite
directive list; nesting depth ≤ D_V.

**Emission rules.** (Z) zero-length runs are dropped — the drop set
of a form is EPT-resolved per cell; (M) merging is NOT an expansion-
time operation: it is built into the forms at production time (the
Merge Lemma below) — the expansion emits exactly one value per
surviving run.

**INV4 (statement).** For every node u of V, per cell: val(u) has a
PPG 𝒢_u with (a) |𝒢_u| ≤ 3^{d(u)}·(2|u|+1) directives (d = S-depth);
(b) nesting depth ≤ d(u); (c) every form's term count ≤ (D_V+2)·M_V;
(d) Exp(𝒢_u) = the run sequence of val(u) (with rule Z).

## 1. Grammar arithmetic (charter item 1)

### 1.1 The type-count depth bound (item 1a)

Let D(u) = directive count. Productions:
 - X: 𝒢 = [F(3^j, [0..k])]: D = 1, depth 1.
 - K: 𝒢 = [T(const)]: D = 1, depth 0.
 - C(A,B): 𝒢_C = 𝒢_A ∘ 𝒢_B with ONE seam: the last run of A and the
   first of B are adjacent b-free a-material and merge (values add).
   The seam production: if A's last emission is a T, fold B's first
   form into it by the Merge Lemma; if it is inside a family F(τ, S),
   SPLIT the family at its last instance — S ∩ [j = hi(k)] and
   S ∩ [j < hi(k)] are both in Ind_1(V) (affine comparison) — and
   merge into the last-instance form. D(C) = D(A) + D(B) + 2.
 - S(R,P,F): section 3: D(S) ≤ 3·D(F) + D(R) + c_0.

Solving the recursion on subtree size: **D(u) ≤ 3^{d(u)}·(2|u|+1)**,
d(u) the S-depth. The exponent 3 is the split multiplicity (each
family directive of the scrutinee splits into at most interior + two
edge-adjusted directives); it is V-fixed because d ≤ D_V. Nesting:
ND(S) = max(ND(F), ND(R)+1) ≤ d(S) since R's S-depth is < d(S).

### 1.2 Seam and junction boundedness (item 1b) — the Merge Lemma

**Lemma (Merge).** The family of forms is closed under (i) addition,
(ii) subtraction of V-fixed constants (bites — PO-1(v): c_0, c_m), and
(iii) per-cell periodic refinement. Term counts: #(τ_1 + τ_2) ≤
#τ_1 + #τ_2 (collect equal exponents; coefficients add — round 5's
COLLECT).

**Boundedness of merged entries.** Merging happens only where
emitted a-material meets without an intervening b, and the production
admits only three sources of such meetings: (1) C-seams (2 pieces);
(2) S-window edges (span edge + insertion edge: 2 pieces, plus the
bite subtraction); (3) junctions INHERITED from the scrutinee's
grammar. By induction, an emitted run is the merge of at most
D_V + 2 pieces (each production step adds at most one meeting point
along any emission path, and there are at most D_V steps). Hence the
grammar-level term bound
  **M′_V ≤ (D_V + 2)·M_V = (D_V + 2)·(8·#S(V) + O_V(1)) = O_V(#S)**:
the round-5 ledger bound survives at the grammar level, with the
depth constant explicit. The number of DISTINCT junction forms is
V-fixed (they are indexed by directive-boundary type, not by
instance), and each C-node contributes at most one seam.

### 1.3 The Theta(k^2) reconciliation (item 1c)

**Proposition.** |𝒢_u| ≤ 3^{d(u)}·(2|u|+1) — k-INDEPENDENT — while
|Exp(𝒢_u, k)| ≤ (k+2)^{d(u)}: polynomial in k of degree ≤ the
S-depth. The k-dependence of the profile lives entirely in the index
ranges (affine in k) and the forms (anchored exponentials): NEVER in
the grammar's combinatorial structure.

This is the reconciliation, and it is why "profile pinned per cell" is
compatible with Theta(k^2) profiles: pinning is a statement about the
GRAMMAR, not the expansion. decb is the canonical witness: 6
directives, expansion (k−1)·k + (k−1) + 2 = k^2 + 1 runs —
machine-verified (101 runs at k = 10). Replication (OF over the fired
set, section 3) scales the EXPANSION, never the grammar: this is the
type-count discipline that keeps D(S) ≤ 3·D(F) + D(R) + O(1) rather
than D(F) + μ·D(R).

## 2. Index-family closure (charter item 2) — stated once, cleanly

**Lemma (AIS-CLOSURE, canonical form).** Every Π ∈ Ind_d(V) admits,
per residue class of (k, j_1..j_d) mod T_V, a description as a
Boolean function of (i) the order type of the V-fixed-finitely many
affine functions αk + Σβ_r j_r + γ (against each other and against
V-fixed thresholds), and (ii) finitely many EPT-tests, each
eventually periodic in each coordinate with V-fixed pre-period and
period dividing T_V^* := T_V · A_V (A_V = max V-fixed substitution
coefficient). Consequently, on the affine-bounded domain, Π is
eventually periodic in each coordinate and exactly periodic outside a
boundary band of V-fixed width. Moreover Ind is closed under the
generation operations, Boolean operations, V-fixed affine
substitution, and bounded projection (∃ over an affine range of one
coordinate).

*Proof.* Induction on the generation. Comparisons (a): the finitely
many affine functions partition the domain into finitely many order
regions (a hyperplane arrangement with V-fixed combinatorics); within
a region every comparison is constant. Residues (b) are exactly
T_V-periodic. EPT-tests (c): by round 6's EPT, per cell of the outer
coordinates the test is eventually periodic in the remaining
coordinate (pre-period V-fixed, period | T_V). Boolean operations:
regions, periodic sets, and eventually-periodic sets are closed, and
pre-period widths add. Affine substitution j_r ↦ a j_r + b: maps the
arrangement to itself (affine image), residues to residues mod T_V
(still T_V-periodic in j_r), and exponent functions to exponent
functions (αk + β(a j_r + b) + γ is affine with V-fixed
coefficients, since a is V-fixed); the substituted EPT-test is again
a difference of forms, so EPT applies with period dividing
T_V^* = T_V·A_V. Bounded projection: per outer-cell the predicate is
eventually periodic in the projected coordinate; the existential over
an affine range is decided by the periodic part (empty/full) plus
finitely many boundary cases, both V-fixed. ∎

Two uses in the production: the mask predicates (section 3) and the
preimage of the fired set under the LINEARIZATION map — the affine
map from (instance tuple, entry position) to the emission ordinal
(whose coefficients are the V-fixed entry counts per directive).

## 3. The S-case production rules (charter item 3)

Setting: the pass [R/P]F; T = val(F) with grammar 𝒢_F; p = val(P)
with P's own grammar; the fired set Φ (PO-3: an eventually-periodic
set of b-stretches — in the linearized ordinal space, an
Ind_1(V)-predicate after pulling back along the V-fixed affine
linearization; AIS-CLOSURE); the bites c_0, c_m (PO-1(v): P's own
boundary run values, pinned by subtree induction on P).

**(S-i) SPAN RULE.** Each family directive F(τ, S) of 𝒢_F becomes
F(τ, S ∩ M) where M = the mask "emission not inside a window
interior" (an Ind-predicate: the complement of Φ's interiors,
pulled back along the linearization). The O(1) directive-splits at
the mask's boundary carry bite-adjusted forms: the run before β_0
keeps value τ − c_0 (the window ate its LAST c_0 a's — legal: PO-1(i)
guarantees the head-run ≥ c_0, so τ − c_0 ≥ 0), the run after β_m
keeps τ − c_m. The edge predicates (left/right boundary of the mask)
are in Ind (boundaries of eventually-periodic sets: EPT). The b-free
(tiling) case is the same rule with the pinned phase arithmetic
(round 5): the mask is the complement of the tiled interiors, an
arithmetic-progression structure in the emission ordinals — residues
mod |p|, and |p| divides T_V by definition.

**(S-ii) INSERT RULE.** The output grammar gains OF(𝒢_R, Φ_lin): R's
directive list re-instantiated once per firing, ambient index = the
firing ordinal. R's first/last runs merge with the adjacent span-edge
forms (at most 2 merges per firing; Merge Lemma). If R's value is
empty, no insertion directive is emitted (the mask alone remains).
R's inner index variables are α-renamed; its forms' arity grows by
one (the ambient firing index), staying within D_V.

**(S-iii) SIZE RULE.** D(S) ≤ 3·D(F) + D(R) + O(1); nesting depth
≤ max(ND(F), ND(R)+1) ≤ d(S).

**Where the fired set is consumed — exactly two points.** Φ enters
the production ONLY as (1) the OF instance set in (S-ii) and (2) the
masks and edge predicates in (S-i). NOWHERE ELSE: the output's VALUE
forms are built from F's forms, R's forms, and V-fixed bite
constants; positions-as-values never enter. This is the round-6
circularity-breaker made precise at the grammar level: the match
tests that DEFINE Φ are EPT-equalities between 𝒢_F entries and P's
entry forms — INV4(F) and INV4(P) data only.

**The combined induction closes:** INV1–INV5 (round 6) with INV4 in
the present line-by-line form: each is preserved by K/V/C/S given
the others; base X. TL and PO stand at full altitude.

## 5. Secondary: the paper-ready TL statement

LaTeX, in the paper's language (round-5 candidate (c), now
unconditional; Lane A mounts this at integration):

```latex
\begin{theorem}[Truncation Ledger over $\mathcal D(k;3)$]
\label{thm:TL}
Fix a substitution expression $V$ over the two-letter alphabet, and
let $\mathcal D(k;3)=a^{3^0}ba^{3^1}\cdots ba^{3^k}$. Write
$S=(3^{k+1}-1)/2$ and let $T_V$ be the $V$-fixed modulus
$\mathrm{lcm}\bigl(\{2\}\cup\{\mathrm{ord}_p(3),\,|p|\}\bigr)$ over
the pattern lengths and tiling moduli occurring in $V$. Then every
run of $V(\mathcal D(k;3))$ has value
\[
v \;=\; \sum_{i\le M} q_i\,3^{e_i}\;+\;(Ak+B)\;+\;\beta ,
\]
where:
\begin{enumerate}
\item[\rm(i)] \emph{strata.} The slopes $q_i\in\mathbb Q$ and the
affine data $A,B$ are $V$-fixed on each residue class of $k$ modulo
$T_V$; each exponent $e_i$ is \emph{anchored}: a sum of at most three
terms from $\{\,k-c,\; j-c',\; c''\,\}$ with $V$-fixed offsets,
where $j$ ranges over the input sites $0,\dots,k$.
\item[\rm(ii)] \emph{term ledger.} The site-reference count obeys
$M\le 8\,\#S(V)+O_V(1)$, where $\#S(V)$ counts substitution nodes;
the first and last runs satisfy $M\le 2$, with only top-anchored
(and products of two top-anchored) exponents.
\item[\rm(iii)] \emph{junk.} $|\beta|=O(k)$, and $\beta$ collects
to a $k$-affine part plus a $T_V$-periodic part.
\end{enumerate}
Moreover the run \emph{profile} is pinned in the same sense: there
is a $V$-fixed \emph{profile grammar} — a directive tree of
$O_V\!\left(3^{d}\!\cdot\!|V|\right)$ nodes, $d$ the
substitution-depth of $V$, whose directives are single values,
index families $j\in[\ell(k)..h(k)]$ with $\ell,h$ affine in $k$,
and outer families instantiating sub-lists — whose expansion, over
forms as in (i)--(iii), is exactly the run sequence of
$V(\mathcal D(k;3))$. The expansion may have length
$\Theta(k^{d})$; the grammar is $k$-independent.
\end{theorem}
```
